# commUnity (Student Living Assistant)
A student residential community platform designed to simplify communication, 
maintenance, events, and access to important residential information.

## Problem
Students living in shared accommodation often face fragmented communication,
unclear responsibilities, difficulty accessing residential information, and
inefficient ways of reporting maintenance issues.

commUnity was designed to address these problems through a centralised
residential community experience.

## Key Features

- Account registration and secure login
- Residential community onboarding
- Personalised dashboard
- Group and direct messaging
- Community announcements
- Maintenance request submission and tracking
- Residential rules and document repository
- Community events and RSVP
- Payment and task management
- Personalisation and privacy controls
- Accessibility-focused interface
